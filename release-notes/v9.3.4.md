Racket 9.3.4 Windows portable artifacts, per architecture (x86_64, arm64):

- **`-setup-cached.exe` (recommended)**: installer with the system compiled cache prebuilt for the default install directory (`C:\Program Files\Racket9`). Default installs finish in 15-20 seconds with no compilation step and start `racket -l racket/base` in 0.2-0.3 s. Custom `/DIR=` or `/CACHEPATH=` installs rebuild the cache like the plain installer. Unattended: `/VERYSILENT /SUPPRESSMSGBOXES /NORESTART`.
- **`-setup.exe`**: plain installer; builds the compiled cache on your machine during installation (about 3.5 minutes on CI hardware). Smallest download.
- **`.zip`**: portable, no installation; runs from source (no compiled cache), so startup is markedly slower - fine for quick trials.

All six artifacts are verified end to end in CI (install, runtime smokes including TLS and `racket/random/generator`, cache validation, uninstall) by the `poc installer e2e` workflow.
