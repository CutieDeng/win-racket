Racket 9.3.5 Windows portable artifacts, per architecture (x86_64, arm64):

- **`-cached.zip` (recommended for portable use)**: the portable tree with everything precompiled in-tree, so it works at any extraction path and starts `racket -l racket/base` in about half a second (the plain zip takes ~12 s). No installation, no registry, delete to remove.
- **`-setup-cached.exe` (recommended installer)**: system-wide install with the compiled cache prebuilt for the default directory; installs in 15-20 seconds. Custom `/DIR=` or `/CACHEPATH=` installs rebuild the cache. Unattended: `/VERYSILENT /SUPPRESSMSGBOXES /NORESTART`.
- **`-setup.exe`**: plain installer; builds the compiled cache during installation (about 3.5 minutes on CI hardware). Smallest installer download.
- **`.zip`**: all-source portable tree; slowest startup, smallest archive.

All eight artifacts are verified end to end in CI (install/extract, runtime smokes including TLS and `racket/random/generator`, cache validation, uninstall) by the `poc installer e2e` workflow.
